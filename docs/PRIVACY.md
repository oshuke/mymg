# 隐私说明

本说明对应本仓库源码。项目未接入作者运营的后端、广告或统计 SDK；使用联网功能仍会向相应服务方发送数据，不能理解为“所有数据永远不离开手机”。自行修改源码、配置服务或引入数字钥匙实现会改变数据流。

## 本机存储

| 数据 | 当前存储方式 |
|---|---|
| 登录令牌、VIN、手机号、userId、设备标识、车辆配置 | 应用的 SharedPreferences，未做应用层加密 |
| 控车 PIN、AI API Key、WebDAV 密码 | flutter_secure_storage；Android 使用 KeyStore 保护的加密存储 |
| 车况快照、历史行程、位置、AI 解读 | 应用私有文件/SQLite/偏好，未统一加密 |
| 自定义车辆图片 | 复制到应用私有目录；恢复默认会移除应用内副本，原始照片仍在相册 |
| 诊断日志 | Flutter/Android 日志；可能含位置、接口响应、标识或错误上下文 |

应用沙箱不等于额外加密，root、设备备份、系统迁移及日志导出会改变可访问范围。卸载通常清理应用本地数据，但不会删除用户导出的文件、云端备份或系统保留的副本。

## 网络数据去向

| 功能 | 接收方与数据 |
|---|---|
| 登录、车辆状态、控车、后台刷新 | 构建时配置的车辆服务；可能包含令牌、VIN、手机号、账号/设备标识和控制请求。配置后可由后台任务发起 |
| 验证码 | 配置的验证码服务及其 SDK；处理验证码交互和必要网络/设备信息，适用该服务的政策 |
| 在线地图 | 仅在构建时提供有效图源和署名后启用；图源收到 IP、地图瓦片编号/缩放等级，可推断查看区域 |
| 地址解析 | `MYMG_ENABLE_PUBLIC_GEOCODING=true` 才启用，默认关闭。启用后 BigDataCloud、Nominatim/OpenStreetMap 会收到车辆坐标及 IP；首页、位置、快捷控车等读取地址时可能自动请求 |
| DNS 回退 | 请求失败时可能使用阿里 DNS-over-HTTPS、DNSPod 的 HTTPS 解析接口；解析方可看到请求域名和 IP |
| 外部导航 | 用户选择打开地图应用/网页时，目标应用或服务收到车辆坐标和目的地名称 |
| AI 解读/聊天 | 配置的模型服务收到请求中的车况、历史行程、时间、位置、消息及提示词；启用自动分析后可自动发送，API Key 用于认证 |
| WebDAV 备份 | 用户配置的服务收到备份文件和认证信息；启用自动备份后可自动上传 |

网络服务通常还能看到 IP、User-Agent 和请求时间。开源版未配置车辆协议时车辆服务不可用，但不能据此认为其他服务绝无网络请求。请检查对应服务商的隐私政策、使用许可、所在地区和数据保留规则。

## 备份包含敏感信息

当前备份实现除数据库、位置历史、账号/车辆配置外，还会将控车 PIN 与 AI API Key 从安全存储导出到备份内容；不包含 WebDAV 密码，恢复时保留本机登录态。备份包未做应用层加密，压缩/打包不等于加密。

请仅备份到自己可信、访问受控的 HTTPS 存储，不要公开分享备份包、分享链接或凭据。设备端的安全存储保护不会延伸到导出的明文内容。需要加密备份时，应先实现并审查独立加密方案。

## 权限与用户选择

| 权限/能力 | 用途 |
|---|---|
| 网络 | 车辆服务、地图、地址解析、DNS、AI、WebDAV |
| 蓝牙扫描/连接与位置权限 | 数字钥匙扩展点和旧 Android 的扫描要求；开源版不内置厂商 BLE 实现 |
| 通知 | 告警、控车结果、预约提醒及前台服务通知 |
| 前台服务、唤醒锁、开机广播、精确闹钟 | 后台任务、服务与预约 |
| 生物识别 | 使用已保存的控车 PIN 前的本地身份验证 |
| 悬浮层 | 快捷控车入口（可选） |
| 系统图片选择器 | 用户主动替换车辆图片，不上传图片到作者服务 |

可关闭自动刷新、自动 AI、自动备份并清理本机数据；退出登录不等于删除远端备份。撤销凭据请到对应服务账户操作。

## 提交与反馈前

登录页默认不勾选协议；发送验证码或以短信/Token 登录前需明确确认。升级后已有登录态的用户、独立快捷控车入口也需确认新版本说明。当前确认版本与 UTC 时间保存在本机偏好，不上传到作者服务。确认前不会进入车辆功能，后台车况任务也会检查确认状态。用户协议和隐私政策可离线阅读，关于页提供入口。系统权限另由系统逐项授权。

- 不提交本地协议配置、令牌、密钥、备份、数据库或个人日志。
- 对截图及错误报告中的 VIN、车牌、手机号、MAC、设备/账号标识、地址与精确坐标打码。
- 本仓库的界面测试使用合成数据；不要用真实数据替换后提交。
- 发生凭据泄漏时，应及时撤销或轮换；仅删除 Git 最新版本不能保证历史、副本或缓存已消失。
