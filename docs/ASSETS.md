# 界面素材与第三方服务

本次 UI 更新仅发布代码、测试及文档，未新增二进制素材。
公开界面的默认车辆使用 `lib/car_side_illustration.dart` 中的自绘矢量示意图，首页、车况、空调页共用；原有 `assets/car/car_hero.png` 仅为渐变占位背景，不视作车辆照片。
公开源码不包含私人开发目录中的 MG5 外观/内饰照片、厂商宣传图、设计参考图片、模拟器或实车截图。

用户可从本机相册替换车辆图并恢复默认。用户选取的图片保存在应用私有目录，不作为本项目素材发布；如分享截图或自行分发，需确认图片授权并遮挡车牌等信息。

界面组件使用 Flutter Material/Cupertino 图标及现有开源依赖，其许可仍由各依赖规定。项目中的车型、品牌名称用于说明兼容目标，不代表厂商授权、背书或商标许可。

在线地图需自行配置有权使用的 GCJ-02 坐标系 XYZ 图源及非空署名，默认关闭。代码的 GPL 授权不授予地图瓦片、数据、照片、商标或服务接口的使用权；署名也不替代相关许可。地址解析需显式启用并遵守服务限额及署名要求。
